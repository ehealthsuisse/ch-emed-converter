`0b579aa6f3aff10a017498db57048c6504091653`, MIT licence, see `../official/README.md`), with the
comments removed and wrapped in a minimal medication plan (patient of the README example, one
medicament `Med1`, unit `Stk`). Generated by `tools/chmed23a/extract_fixtures.py` (research R13.2).

Finding F8 (research R13): `Single-1.json`, `Cyclic-1.json` and `Sequence-1.json` use draft
property names (`d` instead of `do`, `td` instead of `tdo`). They are kept verbatim and are
refused as non-conforming; the object tables of the specification and the .NET examples cover
the same cases with the final names.
